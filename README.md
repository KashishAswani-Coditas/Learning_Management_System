# Learning Management System (LMS)

## Project Overview


The system supports two main roles:
- Admin
- Employee (can be a manager as well)

The goal of the project is to allow organisations to:
manage employees and managers
create and assign courses
track employee learning progress
conduct assessments
generate certificates
monitor employee learning activity

---

# Functionalities Implemented

## Employee Management
Create employees
Create managers
Assign managers to employees
UUID-based entity IDs

---

## Course Management
Create courses
Add modules to courses
Store YouTube learning links
Fetch course details

---

## Enrollment Management
Enroll employees into courses
Prevent duplicate enrollments
Enrollment validation and authorization

---

## Progress Tracking
Module-wise progress tracking
Progress statuses:
  - NOT_STARTED
  - IN_PROGRESS
  - COMPLETED
Automatic course progress updates based on module completion

---

## Employee Functionalities
View enrolled courses
Update module progress
Track personal course progress
View earned certificates

---

## Assessment Management
Assessment creation
Assessment result tracking
Pass/Fail handling

---

## Certificate Management
Certificate generation after:
  - course completion
  - assessment clearance
View employee certificates

---

## Manager Dashboard
Managers can:
View subordinate employees
View employee enrollments
Track employee progress
Filter employees based on:
  - Bench status
  - Enrollment status
  - Course
  - Progress status

Email Notifications
